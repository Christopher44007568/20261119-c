# 立方体光照探针系统（四面体插值 / 墙面遮挡 / 防漏光）

零依赖的 C++17 参考实现，覆盖动态物体的四点（重心）光照探针插值、墙面
遮挡、曝光差异归一、跨插值面连续着色，以及两个相邻房间之间的漏光测试与
明确回退路径。不依赖 Unity / Unreal，可直接用系统 `g++` 编译运行。

## 构建与运行

```bash
make test   # 15 个单元测试
make demo   # 双房间漏光 / 穿墙 / 全失效回退演示
```

## 目录结构

- `include/lp/types.h` — 向量、线性 HDR 颜色、AABB 墙体与线段遮挡检测
- `include/lp/probe_volume.h` — 立方体网格布点与五四面体剖分、点定位与
  重心坐标
- `include/lp/sampler.h` / `src/sampler.cpp` — 遮挡查询、平滑可用性、
  曝光归一、区域过滤、时间域平滑与三级回退
- `include/lp/scene_builder.h` — 两个相邻房间（一暗一明、曝光差 1 档）
  与隔墙的测试场景
- `tests/` — 轻量测试框架与 15 个单元测试
- `demo/two_room_demo.cpp` — 命令行 HUD，打印四个探针的几何权重、可见度、
  最终权重与可用性

## 关键设计

### 1. 立方体布点与合规四面体化

探针按规则立方体网格放置。每个立方体单元剖分成 **5 个四面体**：一个居中
的正四面体（取四个同奇偶顶点）加四个角四面体；单元按 `(cx+cy+cz)` 奇偶
交替使用两套取向。交替取向保证任意两个相邻单元在共享面上画出的是同一条
面对角线，因此整体是 **conforming（合规）四面体化**，物体穿过单元/插值面
时重心插值天然连续，不会产生接缝跳变。

测试 `every_cube_cell_is_partitioned_into_five_nondegenerate_tets` 用
蒙特卡洛点验证无空洞、无重叠；`shared_cell_faces_use_one_common_diagonal`
逐对相邻单元比对面对角线。

### 2. 四点重心插值

定位到包含物体的四面体后，用边矩阵的逆一次性求出四个重心权重
`(w0, w1, w2, w3)`，边界点用两级 epsilon 容差处理浮点误差。权重恒非负且
和为 1，落在顶点/棱/面上时自动退化为对应的 1/2/3 点插值。

### 3. 墙面遮挡与防漏光

- 墙体用 AABB 描述，`blocksLineOfSight` 用 slab 射线求交判断物体到探针
  的开线段是否穿过墙体（端点贴墙时用 epsilon 偏移避免误判）。
- 每个探针带 `zoneId`（房间号）。**跨区域探针被硬拒绝**：无论隔壁房间的
  探针多亮、权重多大，贡献恒为 0。这是防漏光的硬开关，不可被平滑绕过。
- 同房间内被临时墙体挡住的探针不做单帧硬剔除，而是通过每帧指数逼近的
  `visibility` 平滑渐隐，避免权重突变。可见度状态按物体保存在 `ProbeSampler`
  内部，多个动态物体共享同一探针网格时互不污染。

### 4. 曝光差异

探针保存线性 HDR 颜色与烘焙曝光档数 `exposureBias`。混合前先除以
`2^exposureBias` 归一到统一曝光空间；曝光档数本身在对数空间按相同权重
混合，需要重建实际辐照度时再按 `2^exposureBias` 还原。不同曝光的探针因此
可以直接混合而不产生亮度跳变。

### 5. 颜色不跳变的三层保障

1. 合规四面体化保证同一房间内跨插值面几何连续；
2. 遮挡探针按指数可见度渐隐，而非单帧归零；
3. 采样器输出端再加一层颜色/曝光 EMA。区域标签在穿墙瞬间是离散切换，
   EMA 把这一离散切换摊到若干帧，单帧步长有界（60 FPS 下实测
   `r` 通道最大步长约 0.012，而硬切换约为 0.1）。

### 6. 三级回退与除零防护

按顺序尝试，命中即返回：

1. `TETRAHEDRAL` — 四面体内有效探针的归一化加权；
2. `NEAREST-PROBE` — 物体在网格外，或当前四面体探针全部不可用时，取
   **同区域**且视线无遮挡的最近探针（隔壁亮房永远不会被选中）；
3. `EXPLICIT-FALLBACK` — 同区域没有任何可用探针时，使用构造时显式传入的
   回退颜色。

权重归一化前显式检查 `sum > 0 && isfinite`，不满足就不做除法，直接进入
回退路径；回退路径 `weightSum` 保持 0，杜绝除以零、NaN 或采到隔壁亮色。

## 演示输出解读

`make demo` 分四节：

- **A** 物体停在隔墙暗侧，HUD 显示四个探针的几何权重 / 平滑可见度 /
  最终权重 / 可用性，并统计泄漏到亮房探针的总权重（恒为 0）；
- **B** 小步长从暗房穿过墙走进亮房，报告最大单帧颜色步长；
- **C** 同一房间内从插值面两侧逼近，颜色差为 0；
- **D** 用三块面板搭出密封舱使本房间全部探针失效，确认走显式回退、
  权重和为 0、且没有采样到隔壁房间。

## 接入真实引擎的映射

- `Box::blocksLineOfSight` 可替换为引擎的 `Physics.Raycast` /
  碰撞体线段检测；
- `Probe` 的 `color` / `exposureBias` 对应烘焙的 SH/L2 探针数据与曝光元
  数据，颜色通道可直接换成 SH 系数数组，插值规则不变；
- 每帧调用一次 `ProbeSampler::sample(position, deltaTime)`，把返回颜色
  赋给动态物体的环境光/IBL 项，HUD 字段可直接对接调试面板。
